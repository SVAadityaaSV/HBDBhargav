# HBD Bhargav

A two-page birthday card, plain HTML and CSS (no build step, no dependencies).

- `index.html`  - front of the card (Page 1)
- `inside.html` - patch notes inside (Page 2)

## Publish with GitHub Pages
1. Put these files in the root of the repo and push.
2. Repo Settings > Pages > Source: "Deploy from a branch" > `main` / `(root)` > Save.
3. Open `https://<your-github-username>.github.io/<repo-name>/` after a minute or two.

Fonts (Bagel Fat One, Fredoka, Space Mono) load from Google Fonts.
